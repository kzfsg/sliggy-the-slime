# Sliggy the Slime

**🏆 NUS GameCraft 2023 — Champion**

A puzzle-platformer where every death turns Sliggy into a block. Guide Sliggy through Dr. Doofus's laboratory, using your own remains as platforms to reach the exit and take down the bosses waiting at the end.

▶️ **[Play it on itch.io](https://kzfsg.itch.io/sliggy-the-slime)**

## Controls

| Action | Keys |
|---|---|
| Move | ← → / A D |
| Jump | ↑ / W / Space |
| Drop through platforms | ↓ / S |
| Return to spawn | R |
| Clear blocks | C |

## Running locally

1. Install [Godot 4.2](https://godotengine.org/download/archive/4.2-stable/).
2. Open `project.godot` in the Godot editor.
3. Press **F5** to play.

## History

The game was built over four days, December 12–16, 2023 (Singapore time). The team passed versioned zips around for the first three days and switched to git on day four. This repository puts both together:

- **v0.0 – v0.8**: zip snapshots, committed with the original save times.
- **From Dec 15**: the team's original git history, with authors and timestamps unchanged.
- **Side branches** (`jake-v0.9`, `jeric-v0.9`, `jake-v0.12`, ...): teammates' parallel versions that were merged in by hand.
